Support us

Popup Style

Controls the hover QuickCard and selection search popups shown on a web page. The toolbar popup (clicking the extension icon) always shows Full.

Topics

Which topics QuickCard should search. At least one must stay checked - checking or unchecking one enables or disables its tab on the left.

General

How long to wait, in milliseconds, after you select text before the search icon appears next to it. Click that icon to open the popup.

Site Rules (all topics)

A single site list that applies to every topic. separate from each topic's own hover-only list on its own tab. This one can restrict the hover QuickCard, the text-selection popup, or both. It never affects context menu search or the toolbar popup, and those always still work everywhere.

Applies to

Which feature(s) this list restricts.
Whitelist / Blacklist site lists
Used only when "Only run on these sites" is selected.
Used only when "Run on all sites except these" is selected. Empty by default - add sites here (e.g. google.com) to stop the hover card and/or selection popup from getting in your way on them.

Backup

Export every setting to a text file (all topics: toggles, site rules, custom links, regions, …). Import replaces current settings with the file.

Custom Links
Add your own link buttons under a card (titles and people). Built from a URL template you provide — no API involved. If the target site uses a different slug format than you expect, the link may not resolve to the right page.
Placeholders: {imdb_id} (e.g. tt0133093 or nm0000138), {title} (URL-encoded name), {title_dash} (lowercase-dashed slug).
